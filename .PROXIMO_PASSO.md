# Próximo Passo — Integração WooCommerce ao Vivo

**Status:** API compilando (nest-cli.json + tsconfig.build.json criados pra excluir specs)

## Quando API ficar pronta (localhost:3009):

### 1. Gerar API Key via Dashboard

```bash
# Abrir dashboard
http://localhost:5175

# Login: demo@zyon.com
# Senha: (pode registrar nova conta ou usar JWT do __test__/seed)
```

### 2. Criar API Key com escopo `embed:sessions:create`

```bash
# Via API (depois que estiver logado):
POST /merchant/api-keys
{
  "name": "WooCommerce Plugin",
  "scopes": ["embed:sessions:create"]
}
```

### 3. Configurar Plugin

```bash
# No WordPress:
WooCommerce > Zyon Checkout Settings

- Merchant ID: demo@zyon.com
- API Key: <copiar da dashboard>
- API URL: http://host.docker.internal:3009
- Webhook Secret: (já configurado)
```

### 4. Testar Fluxos

**Embed:**
```bash
GET /embed/session  # WP plugin chama isso
retorna: { embed_session_token: "..." }
```

**Webhook (order.paid):**
```bash
POST /webhooks/woocommerce/demo@zyon.com
{
  "event": "order.paid",
  "data": { "order_id": "123", "total": 100, "currency": "BRL" }
}
# Header: x-wc-webhook-signature: <HMAC-SHA256>
```

### 5. E2E — Checkout Real

```bash
# Abrir checkout WooCommerce
http://localhost:8080/checkout

# Widget deve aparecer (inline mode)
# Clicar no widget
# Conversa com IA deve carregar
# Completar pagamento
# Ordem deve aparecer no dashboard
```
