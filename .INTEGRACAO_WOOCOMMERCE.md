## Passos de Integração

### 1. Login no Dashboard
- Abrir `http://localhost:5175`
- Fazer login com merchant demo@zyon.com

### 2. Conectar WooCommerce
- Ir em "Integrações" → "Comércios"
- Clicar "Adicionar Integração" → "WooCommerce"
- Preencher:
  - **Store URL:** `http://localhost:8080`
  - **Consumer Key:** (usar chave gerada — ver abaixo)
  - **Consumer Secret:** (usar secret gerado — ver abaixo)
- Clicar "Conectar"

### 3. Testar Widget no Checkout
- Abrir `http://localhost:8080/checkout`
- O widget deve aparecer após configurar a connection
- Verificar que o tag `<zyon-checkout-agent>` está presente

### 4. Testar Webhook (order.paid)
- Criar pedido no WooCommerce
- Marcar como "paid" via admin
- Plugin deve fazer POST a AACP em `/commerce/woocommerce/webhook` com HMAC válido
- AACP processa e atualiza order status
