## 2. WEBHOOK ENDPOINTS & AUTHENTICATION

### Inbound Webhooks (Signature-Validated, No JWT)

POST /webhooks/whatsapp/bubblewhats/messages
  Auth: Header x-webhook-secret (string equality)
  Body: BubbleWhatsMessagePayload { id, fromNumber, toNumber, body, deviceID, isGroup }
  Processing: async via MessageDebouncerService

POST /webhooks/whatsapp/bubblewhats/status
  Auth: Header x-webhook-secret
  Body: BubbleWhatsStatusPayload { deviceID, messages[] }

POST /webhooks/whatsapp/twilio
  Auth: Header x-twilio-signature (HMAC-SHA1 + timingSafeEqual)
  Signature: HMAC-SHA1(authToken) on url + sorted params
  File: twilio-signature-validator.ts:line 21-42

### Dashboard Config Endpoints (JWT-required)

GET /merchants/:merchantId/whatsapp/connection
  Returns: { status, enabled, provider, whatsappNumber, connectedAt }

POST /merchants/:merchantId/whatsapp/meta/connect
  Body: { code, wabaId, phoneNumberId }
  Action: Embedded Signup (exchanges Meta OAuth for WABA token)

POST /merchants/:merchantId/whatsapp/twilio/connect
  Body: { phoneNumber, provider? }

POST /merchants/:merchantId/whatsapp/twilio/verify
  Body: { otpCode }

## 3. TWILIO INTEGRATION

Method: Raw fetch (NOT twilio npm SDK)

Request:
  POST https://api.twilio.com/2010-04-01/Accounts/{accountSid}/Messages.json
  Auth: Basic {base64(accountSid:authToken)}
  Body: URLSearchParams { To: 'whatsapp:+55...', From: 'whatsapp:+55...', Body: text }

Credentials (per-merchant in WhatsAppConfig):
  accountSid, authToken, senderId (format: whatsapp:+5521989825798)

Adapter: twilio-sender.adapter.ts lines 53-90

## 4. CART RECOVERY FLOW

Scanner (recovery-scanner.job.ts:line 68):
  - Every 15 min via setInterval
  - Polls CheckoutSession WHERE triggerAgent=true AND no RecoveryAttempt
  - Classifies reason + selects strategy + sends WhatsApp + email

Abandonment Detection:
  1. Load session (items, cart total)
  2. Load buyer history
  3. Classify reason (shipping_cost|price|trust|payment|unknown)
  4. Query MerchantRule for strategy

Session Update:
  CheckoutSession.authorizedOffer = { type, value, validUntil }

## 5. POST-SALE FLOW

Trigger: order_completed event

Template Types (6):
  follow_up, review_request, nps, cross_sell, win_back, loyalty, reorder

Generation: OpenAI via PostSaleAiCopywriterService

Queue: BullMQ every 5 min (CRON */5 * * * *)
  Fallback: setInterval if no Redis

Processing: poll ScheduledMessage (status=pending && sendAt <= now)

Buyer Interactions:
  POST /post-sale/reviews
  POST /post-sale/nps
