# Stack

- Runtime: Node.js 20+
- Package manager: pnpm workspaces
- API: NestJS
- Frontend: React + Vite
- Widget: React mounted as a Web Component
- Language: TypeScript strict mode
- Persistence: in-memory for MVP, PostgreSQL target
- Commerce integration: Multi-platform adapters (WooCommerce, Magento, VTEX, Tray — see INTEGRATIONS.md)
- LLM integration: OpenAI Responses API
